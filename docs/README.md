# Project documents

Start with the [EvidenceAtlas Food project report](EvidenceAtlas_Food_Report.pdf), [status](STATUS.md) and [open issues](OPEN_ISSUES.md). The project report describes the current collection, retrieval system, local LLM summaries, evaluation and limitations. `REPORT.md` is its text companion. `REPORT_2026_10_07.md` and `EvidenceAtlas_Food_Report_2026_10_07.pdf` preserve the October report as a historical snapshot.

`DEMO_SCRIPT.md` is the live demonstration plan. `SPECIFICATION.md`, `DELIVERY_SCOPE.md` and `COURSE_REQUIREMENTS.md` preserve original requirements. `ARCHITECTURE.md`, `DECISIONS.md` and `PLAN.md` record design decisions. `SETUP_REFERENCE.md` and the root README provide installation instructions.

`checks/` contains measured verification records; `screenshots/` contains interface images. Earlier checks describe their dated snapshots, not the current collection.
